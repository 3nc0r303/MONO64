# MONO64 v0.3 — Global PWM + Saw Shape

**Windows VST3 + standalone**, C++17 / JUCE / CMake. Исходный проект: скомпилированного плагина `.vst3` в архиве нет. DSP-движок проверен отдельными C++ тестами (GCC и Clang на Linux); GUI и VST3 требуют сборки и проверки на Windows.

## Новое в v0.3: общий PWM, включая пилу

Добавлен отдельный **GLOBAL PWM + SAW SHAPE** модуль, который действует на **все три унисонных осциллятора одновременно**. Саб-осциллятор не меняется. У обеих форм волны общий параметр:

- `PW / SHAPE` (5–95%, по умолчанию 50%). При 50% — неизменённая классическая пила и квадрат. При других значениях `Square` — прямоугольный импульс переменной ширины (настоящий PWM); `Saw` — пила с асимметричным участком роста через **фазовое искажение/phase warp** (не стандартная «ширина импульса», поскольку у обычной пилы ширины импульса нет).
- `MOD RATE` (0.02–20 Гц, по умолчанию 0.3): частота отдельного свободно бегущего синусоидального модулятора формы.
- `MOD DEPTH` (0–100%, по умолчанию 0): глубина, которая добавляет до ±45 процентных пунктов к PW/Shape. Общий результат ограничен безопасным диапазоном 5–95%.
- Дополнительно у LFO 1/2 теперь есть назначение `PWM / Shape`, одновременно суммируемое с dedicated PWM модулятором. Это позволяет, например, модулировать Saw треугольным LFO, а Square — тем же общим движением. Отдельных PW ручек на осцилляторах нет — **одна ручка для всех**.
- Для автоматизации ручек в DAW и модуляции есть сглаживание 5 мс. Для сглаживания резких краёв PolyBLEP применяется на скачках пилы и импульса; крутой угол наклона фазово-деформированной пилы при экстремальных значениях может создавать дополнительный алиасинг (будущая версия может добавить oversampling/BLAMP).
- JUCE-хост видит `pw`, `pwm_rate` и `pwm_depth` как автоматизируемые VST-параметры. Старые параметры предыдущей версии сохранены с теми же ID для совместимости.

**Пример:** поставь `PW = 50%`, `MOD RATE = 0.35 Hz`, `MOD DEPTH = 65%`, подними Saw и Square — обе формы начнут двигаться синхронно, а SUB останется чистым. Или отключи встроенный PWM (`MOD DEPTH = 0`) и назначь `LFO 1 → PWM / Shape`.

## Сохранилось из v0.2

- **Только Saw и Square** в трёх основных осцилляторах. Sine и Triangle удалены из генераторов унисона. Noise тоже убран.
- **Монофония + до 64 унисонных голосов**: все голоса играют одну MIDI-ноту; три осциллятора имеют собственные настройки волны/октавы/уровня. Основные осцилляторы используют PolyBLEP для уменьшения алиасинга.
- **Независимый SUB**: ровно 1 синусоидальный голос, строго по центру, регулируемый уровень и -1/-2 октавы. Синус остался **исключительно в саб-осцилляторе**; его нет в выборе формы основных осцилляторов.
- **Двойной High-pass модуль на унисоне**, полностью независимый от саба:
  - `UNISON HP`: срезает частоты по обоим каналам всего унисонного сигнала (L/R), 20–16000 Гц.
  - `SIDE HP`: срезает частоты **только в Side-компоненте** стереосигнала унисона (`Side=(L-R)/2`), не меняя `Mid=(L+R)/2`. 20–16000 Гц.
  - В обоих фильтрах есть **вкл/выкл** и **12/24 дБ/октаву**. Фильтры идут последовательно. Срезы полностью независимы. По умолчанию UNISON HP 100 Гц, SIDE HP 180 Гц, оба 24 дБ/октаву.
- **Цветной частотный анализатор** (live FFT 4096): **бирюзовый = унисон** (суммарная энергия каналов L/R после HP), **оранжевый = моносаб**. Ось частоты — логарифмическая, 30 Гц — 20 кГц, уровень — дБ. Анализатор показывает компоненты отдельно, **до их суммирования и общего защитного насыщения**, поэтому графики не следует понимать как точную спектральную декомпозицию финального нелинейно ограниченного выхода.
- Унаследованы 2 LFO (Sine/Triangle/S&H — это **модуляторы**, не основные звуковые генераторы), 2 ADSR, основной резонансный Low-pass для унисона, Drive, Glide, Legato, Pitch Bend, Detune, Spread, Drift Depth/Rate и индивидуальная амплитуда голосов.

## Аудиомаршрутизация

```text
MIDI NOTE ──┬── OSC 1/2/3 (Saw/Square × 1–64 унисонных голосов)
            │          ↑ ONE GLOBAL PW/SHAPE + PWM LFO  (NOT ON SUB)
            │          └── AMP ADSR → UNISON LOWPASS → DRIVE
            │                         → UNISON HP (L/R, 12/24 dB/oct)
            │                         → MID/SIDE: SIDE HP (12/24 dB/oct)
            │                         → UNISON ────┐ [бирюзовый FFT]
            │                                      │
            └── SUB (Sine ×1, -1/-2 октавы, MONO) ├── MASTER → SOFT CLIP → L/R OUT
                          └── AMP ADSR ────────────┘ [оранжевый FFT]

SUB НЕ проходит через UNISON LP/DRIVE/HP/SIDE HP.
```

### Для чего нужны два среза

При басовом унисоне `UNISON HP` освобождает низ для чистого саба. `SIDE HP` можно поднять ещё выше, чтобы низ оставался близким к моно, а ширина начиналась только на средних/высоких частотах. Пример: UNISON HP = 120–180 Гц, SIDE HP = 250–450 Гц, саб на -1 октаву; подстрой по спектру и на слух.

## Сборка на Windows

1. Установить **Visual Studio 2022 Community** с пакетом **Desktop development with C++**, Windows SDK и MSVC.
2. Установить **CMake 3.22+** и **Git** (чтобы CMake мог скачать JUCE при первом конфигурировании).
3. Распаковать архив и запустить `build_windows.bat`.
4. Найти `build\MONO64_artefacts\Release\VST3\MONO64.vst3`. **Копировать всю папку/bundle `MONO64.vst3`** в `C:\Program Files\Common Files\VST3\`.
5. В FL Studio: `Options → Manage plugins → Find installed plugins`. Играйте MIDI-нотами или экранной клавиатурой.

Чтобы использовать уже скачанный JUCE, вместо автоматической загрузки:

```bat
cmake -S . -B build -G "Visual Studio 17 2022" -A x64 -DJUCE_DIR="C:/path/to/JUCE"
cmake --build build --config Release --parallel 4
```

Если v0.1 уже установлен, пересобери v0.3 **в отдельной папке сборки**, затем замени старый bundle VST3 новым. Поскольку выбор волны у осцилляторов теперь состоит из двух значений, **пресеты v0.1 могут интерпретировать волну иначе; v0.2 использует ту же пару Saw/Square**.

## Тесты без JUCE (отдельное DSP)

Linux/macOS, C++17:

```sh
./tests/run_linux.sh
c++ -std=c++17 -O2 tests/render_demo.cpp -o /tmp/mono64_demo
/tmp/mono64_demo demo.wav
```

`tests/engine_test.cpp` проверяет полифонию внутри унисона, моно-стек клавиш, изоляцию саба, подавление НЧ фильтром 24 дБ, сохранение Mid при фильтрации Side, классическую форму волны в положении 50%, изменение Saw и Square общим PW, PWM LFO и независимость саба. `tests/render_demo.cpp` создаёт 7-секундный стерео WAV. DSP-тесты можно провести GCC и Clang на Linux; результат актуальной сборки указан ниже.

## Реализация и ограничения

- `Source/SynthEngine.h` — DSP без внешних зависимостей.
- `Source/PluginProcessor.cpp` — JUCE процессор, параметры/автоматизация, GUI, FFT-анализатор.
- Между аудиопотоком и интерфейсом используется **SPSC lock-free FIFO**. FFT выполняется только в GUI-таймере, не в аудиопотоке; обмен данными не выделяет память в процессе обработки звука.
- HP использует два последовательно соединённых 12-дБ SVF-звена для режима 24 дБ. Для резкой автоматизации cutoff пока нет кроссфейда, возможны лёгкие артефакты движения фильтра.
- На 64 × 3 осцилляторах процессор нагружается заметно сильнее, чем на 8 × 2.
- Сам VST3/GUI **не протестированы в Windows/FL Studio** в текущем окружении. При возникновении ошибки компиляции сохрани лог сборки и пришли его для исправления.
