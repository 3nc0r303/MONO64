# Сборка MONO64 на Windows без Visual Studio у себя

Этот архив содержит **исходники**, а не уже собранный плагин. Файл
`.github/workflows/windows-vst3.yml` запускает компиляцию VST3 на
Windows-2022 в GitHub Actions. Сборка требует доступа runner-а к GitHub,
чтобы скачать JUCE 9.0.4.

## Порядок действий

1. Открой https://github.com/new, создай **отдельный публичный (Public) репозиторий** `MONO64`. В публичных репозиториях обычные GitHub-hosted Windows Actions бесплатны даже после исчерпания минут приватных репозиториев. **Осторожно:** исходники станут доступны всем. Не делай публичным свой основной MIDI-секвенсор и не загружай секреты.
2. Загрузить в него **все файлы и папки** этого проекта, обязательно
   включая скрытую папку `.github/workflows` (удобно через GitHub Desktop
   или Git CLI).
3. Открой репозиторий → **Actions** → **Build MONO64 Windows VST3**.
   Если GitHub попросит включить Actions для репозитория — включи.
4. Нажми **Run workflow**, выбери основную ветку и запусти. При push на
   `main` или `master` workflow также запускается автоматически.
5. **Только если сборка завершилась зелёным:** открой запуск и скачай
   artifact `MONO64-v0.3-Windows-VST3`. Распакуй его, внутри будет
   `MONO64_v0.3_Windows_VST3.zip`.
6. Распакуй и этот ZIP: должна появиться **папка `MONO64.vst3`**.
   Скопируй *всю папку* в `C:\Program Files\Common Files\VST3\`.
7. В FL Studio открой Options → Manage plugins → Find installed plugins.

Если GitHub Actions покажет ошибку, передай текст из упавшего шага:
исходники JUCE/Windows ещё не были полностью скомпилированы и
проверены в хосте FL Studio в текущем окружении.

Примечание: условия лицензирования JUCE применяются отдельно; при
публикации/распространении бинарного VST3 проверь лицензию JUCE.

## Если бесплатные минуты Actions закончились

В приватных репозиториях сборка может быть остановлена после исчерпания месячной квоты. Стандартные GitHub-hosted Actions в **публичных** репозиториях бесплатны и не расходуют этот лимит: https://docs.github.com/en/billing/concepts/product-billing/github-actions. Поэтому используй отдельный Public-репозиторий только для MONO64. Если открывать исходники не хочешь, есть вариант локальной сборки на своём ПК или ожидания обновления лимита.
